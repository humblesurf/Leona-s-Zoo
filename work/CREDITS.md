# 动物世界素材来源

当前草原、雨林、海洋使用用户于 2026-10-06 上传的三张原始 2172×724 PNG，保存在 assets/bg/reference/*-preferred-v4.png；原像素、构图和风格保持不变。完整高度按 3:1 显示，以镜像延续画卷。

极地背景、角色与树枝支撑素材使用内置 image_gen 生成。V4.2 老虎、农场、菜市场及动物宝宝的完整提示词和源图路径见 assets/generation-v4-2.json，源 PNG 保存在 assets/animation/v4-2。采用机械透明轮廓裁切和质量 98 的 WebP 编码。原有 V4 / V4.1 生成记录继续保留。29 个角色采用同一幅角色画的连续刚性关节绘制，七种果蔬用原生 Canvas 几何开合，35 个原有角色保留 16 姿态整帧动画；冰屋使用暖光互动。未使用网格变形。

三语介绍：Microsoft Edge neural TTS，通过 edge-tts 制作。每种语言三位讲述者，随机轮换、不连续重复。英语 Ana 童声 / Andrew 男声 / Emma 女声；粤语 HiuMaan / WanLung / HiuGaai；普通话 Xiaoxiao / Yunxi / Yunxia。Yunxia 是少年感的卡通男声，粤语为成人男声及女声。V4.1 的 495 段原录音保留；移除鸵鸟后，其中 486 段在当前场景使用。V4.2 另加入 18 种对象的 162 段录音，共 648 段实际使用的介绍。文本和设置分别见 assets/voice/v4-1 与 assets/voice/v4-2 内的 script.json、production.json。
